# WHILL Model CR を踊らせる

作成：2026-11-02

人のダンスに合わせて踊る仕組み（pose_dance）を、WHILL Model CR（研究開発用の電動車いす）で動かす。Model CR は RS232C のシリアル通信で外から操作でき、WHILL 社の Python のライブラリ pywhill（`pip install whill`）で指令を送る。

## 1. 仕組み

```
コンテナ（ROS 2 Jazzy）                           MacBook（Docker の外）                 Model CR
 video_source → pose_detect → pose_dance ──/cmd_vel（Twist）──→ whill_bridge.py ──RS232C──→ ジョイスティックの指令
                                 robot:=whill        rosbridge 9091     （pywhill）
```

- Docker Desktop のコンテナからは USB のシリアルを使えないので、車いすとの通信は MacBook の上で直接動かす `whill_bridge.py` が行う。
- `whill_bridge.py` は、速度の指令を**ジョイスティックの倒し量**（−100〜100）に直して送る。車いすの速度モードと加減速の設定がそのまま効く。
- pywhill の説明では、`side` が + のとき右に回る。ROS は左回りが + なので、符号を逆にして送る（`--side-sign -1`）。

## 2. 安全のための決まり

| 決まり | 内容 |
|---|---|
| 人を乗せない | 試験の間は誰も乗せない |
| 周りを空ける | 車いすの周り 1 m 以上に物や人がいないようにする |
| 電源ボタン | 指令を送っている間は車いすのジョイスティックが効かない。いざというときは**車いすの電源ボタン**を押す。押せる人がそばにいる |
| 速さの制限 | 倒し量は旋回 ±10%、前後 0%（前後に動かない）から始める。上限は 20% |
| ゆっくり動き出す | 倒し量は 1 秒に 20% までしか増やさない。止めるときはすぐ 0 にする |
| 指令が途切れたら止まる | 指令が 0.3 秒届かない、rosbridge が切れた、踊りのプログラムが止まった、のどれでも止まる |
| 停止キー | MacBook の端末で Enter を押すと停止・再開を切り替える。Ctrl + C で終わるときは止めてからジョイスティックを戻す |

## 3. 手順

### 3.1 準備（MacBook、初回だけ）

踊りのプログラムも MacBook で動かす。Docker Desktop を入れて起動し、リポジトリを取ってコンテナを作る（初回はインターネットで約 3 GB を取り、20〜30 分かかる）。

```bash
git clone https://github.com/ba2vwbus13/chibariyo-dance-mimic.git
cd chibariyo-dance-mimic && tools/download_videos.sh
cd docker && docker compose up -d --build
```

ブラウザで http://localhost:6081 を開き、デスクトップの Terminator でビルドする。

```bash
cd ~/ros2_ws && colcon build --symlink-install
```

MacBook の端末（Docker の外）で、車いすとの通信に使うライブラリを入れる。

```bash
pip3 install whill websocket-client
```

USB-RS232C のケーブルで Model CR と MacBook をつなぎ、装置名を調べる（`/dev/cu.usbserial-XXXX` のような名前）。

```bash
ls /dev/cu.usbserial*
```

### 3.2 つながるかの確認（動かさない）

車いすの電源を入れてから実行する。電池の残り・速度モード・左右のモータの速さが 5 秒表示されれば、つながっている。

```bash
python3 whill_check.py --port /dev/cu.usbserial-XXXX
```

### 3.3 ごく小さく動かす確認

人を乗せず、周りを空けてから実行する。`yes` と入力すると、ジョイスティック 8% で 1 秒ずつ、前進・`side +`・`side −` の順に動いて止まる。`side +` で右に回れば、pywhill の説明どおりである。

```bash
python3 whill_check.py --port /dev/cu.usbserial-XXXX --test-move
```

### 3.4 踊らせる

コンテナの Terminator で、踊りを `robot:=whill` で起動する（向き ±30°、前後 ±5 cm、前後の速さ 0.1 m/s・旋回の速さ 0.3 rad/s まで）。

```bash
ros2 launch finger_dance pose_dance.launch.py robot:=whill file:=/home/ubuntu/ros2_ws/videos/pexels_10264579_woman_hiphop.mp4
```

MacBook の端末（Docker の外）で、リポジトリの `whill` フォルダに移って橋渡しを動かす。最初は旋回だけで試す。

```bash
python3 whill_bridge.py --port /dev/cu.usbserial-XXXX
```

旋回がうまくいったら、前後の揺れも少しだけ足す。

```bash
python3 whill_bridge.py --port /dev/cu.usbserial-XXXX --front-cap 5
```

車いすにつながずに、送る値だけを確かめるときは `--dry-run` を付ける。

## 4. 確認状況

- `whill_bridge.py --dry-run` と `pose_dance robot:=whill`（ヒップホップの動画）を Mac Studio で動かし、指令が倒し量 ±10% に収まること、左回りが `side −` になること、踊りのプログラムを止めると 0 を送ることを確かめた（2026-11-02）。
- Model CR の実機ではまだ動かしていない。
