# チバリヨカー ダンス物まね（エイサー骨格推定・Gazebo 3Dシミュレーション・WHILL Model CR 実機制御）で動かしたコード

担当の学生が 2026-11-27 に zip で送ったもの（Issue #2）をリポジトリに入れた。もとの説明では、エイサー（ダンス物まね）の骨格推定・Gazebo 3D車いすシミュレーション・実機 WHILL Model CR 制御・CSV記録および視覚化動画生成のために作成・変更したプログラム一式をまとめたものである（大容量の動画ファイルやビルド生成物は入れていない）。
記録・動画は Teams の共有フォルダに置いてある。場所はリポジトリのいちばん上のフォルダから見たもの。

**2026-11-27 に変えたところ（リポジトリに入れるとき）**
- 橋渡し `whill/whill_bridge.py` は、追従の版と一つにまとめた。安全の既定値は元のまま（前後 0%・旋回 10%）で、学生が使った値は `--preset dance-demo` で入る（先生の許可 2026-11-27）。詳しくは `whill/手順.md` の 3.7。
- 自分の PC の場所（`C:\Users\…`）を消し、`--csv`・`--dir` などの引数で渡すようにした。`--port` の既定（COM3）もなくし、毎回付ける。
- `pose_dance.py`・`eisa_dance_node.py` に書いてあった Docker の中の IP アドレスを消した。コンテナの名前・`host.docker.internal`・ゲートウェイで届かないときは、環境変数 `CHIBARIYO_EXTRA_HOSTS` に住所をカンマ区切りで渡す（例 `CHIBARIYO_EXTRA_HOSTS=<GazeboのコンテナのIP>`）。

## 用意するもの
- Docker Desktop（コンテナ finger_dance：http://localhost:6081 / rosbridge 9091番ポート、コンテナ wheelchair_follow：http://localhost:6080）
- Windows 側 Python 環境（実機 WHILL 通信および視覚化スクリプト用）
- 橋渡し（Windows PowerShell）: python -m pip install -r whill/requirements.txt（whill は 1.5.0、websocket-client）
- 骨格のモデル pose_landmarker_full.task（または pose_landmarker_lite.task）：コンテナ内の /opt/finger_dance/ または ros2_ws/models/ に配置
- カメラ（ブラウザ http://localhost:6081/camera.html?port=9091 から Web カメラ映像を送信、またはダンス動画 mirukumunari.mp4 を入力）、WHILL と PC をつなぐ USB-RS232C（Windows の装置名はデバイス マネージャーで調べる。COM3 など）

## 実行コマンド（用途別）

### 1. 実機 WHILL Model CR をカメラ（または動画）の骨格推定で踊らせるとき（ターミナルを 2 つ使う）
ターミナル 1（Docker コンテナ finger_dance 内）: 骨格推定と速度指令 (/cmd_vel)・CSV自動記録を起動
```
ros2 launch finger_dance pose_dance.launch.py source:=camera
```
ダンス動画ファイルで動かす場合:
```
ros2 launch finger_dance pose_dance.launch.py source:=file file:=/home/ubuntu/ros2_ws/videos/mirukumunari.mp4
```
  - カメラを使うときは、ブラウザで http://localhost:6081/camera.html?port=9091 を開いて「開始」を押す
  - 実行中、コンテナ内の /home/ubuntu/ros2_ws/analysis/live_camera_dance.csv および camera_dance_<日時>.csv に骨格データと WHILL 指令値がリアルタイム記録される

ターミナル 2（Windows PowerShell・whill フォルダで）: WHILL への橋渡し。最初に --dry-run で送る値を確かめてから、本番
```
cd whill
python whill_bridge.py --dry-run --preset dance-demo --csv 記録のフォルダ\whill_live.csv
python whill_bridge.py --preset dance-demo --port COM3 --csv 記録のフォルダ\whill_live.csv
```
  - --preset dance-demo の出力上限は 前進 55%・後退 -70%（--back-gain 1.3）・旋回 ±70%・立ち上がり速度 500%/秒・指令が 2.5 秒届かないと止まる（先生の許可 2026-11-27）
  - 路面に合わせて出力を小さくするときは --preset dance-demo --front-cap 40 --side-cap 50 のように後ろに付ける（プログラムの中の最大は前進 55%・後退 70%・旋回 90%）
  - 実行するたびに、指定した CSV と同じフォルダに日時付きの別ファイル（whill_live_YYYYMMDD_HHMMSS.csv）が自動で新規作成され、骨格データと WHILL 指令値の両方が記録される
  - 止める順: ターミナル 2 で Enter（一時停止）または Ctrl + C（終了してジョイスティック解放） → ターミナル 1 で Ctrl + C。とっさのときは車いす本体の電源ボタンを押す

### 2. Gazebo 3D 車いすシミュレーション（localhost:6080）でエイサーを踊らせるとき
ターミナル 1（Docker コンテナ wheelchair_follow 内）: 軽量版 3D 車いすエイサーシミュレーションを起動
```
cd ~/ros2_ws && colcon build --symlink-install && source install/setup.bash
ros2 launch wheelchair_gazebo eisa_dance_demo.launch.py
```
  - カメラ・動画が未接続の間は自動でエイサー基本演舞デモを再生し、finger_dance コンテナ（ターミナル 2）からカメラや動画の骨格データが届いた瞬間に自動でリアルタイム連動モードへ切り替わる
  - 真値オドメトリ（/wheelchair/ground_truth）による閉ループ位置・角度制御と後輪補助キャスターにより、深いしゃがみ込みや連続ステップの後でも初期位置（0.0m, 0.0°）へ正確に戻る

### 3. ダンス動画からオフラインで CSV データを出力・比較視覚化動画（MP4）を作るとき
- ダンス動画（mirukumunari.mp4 等）から骨格推定値と WHILL 指令値の CSV を作成（Docker コンテナ finger_dance 内）:
```
python3 ~/ros2_ws/analysis/offline_dance.py ~/ros2_ws/videos/mirukumunari.mp4 ~/ros2_ws/analysis/mirukumunari_dance.csv
```
- お手本動画（mirukumunari.mp4）の骨格の動きと第 1 段階（物真似の決まり：骨格推定→WHILL）の動きを横並び視覚化（Windows PowerShell）:
```
python ros2_ws/analysis/visualize_mirukumunari.py --csv 記録のフォルダ\mirukumunari_dance.csv
```
- お手本 CSV（mirukumunari_dance.csv）と実測 WHILL CSV（whill_live_*.csv）の比較視覚化動画を作成（Windows PowerShell）:
```
python ros2_ws/analysis/visualize_csv_comparison.py --dir 記録のフォルダ
```
  - --live を付けなければ、そのフォルダのいちばん新しい whill_live_*.csv と比べる

## 骨格推定と車いす（WHILL）の動作対応（第 1 段階：物真似の決まり）
- 人の向いている向き（肩・腰の 3D 座標から算出した yaw_s）を車いすの基本の向き（base_heading）として常時追従し、人と同じ向きを向く。
- 手の動きは骨格推定で判断しない（手を上げながらステップや足上げをしても足の判定が妨げられない）。
1. しこ立ち（優先順位 1）:
   腰の沈み込み率 > 14% かつ 腰〜膝の垂直距離縮小率 > 10% を検出 → 人の向きを保ったまま後ろに下がる（基準 -0.12m / 大振幅 -0.30m）。立ち上がると元の位置（0.0m）へ戻る。
2. turn（1 回転）:
   体の向き |yaw| > 110°（後ろ向き：HALF_TURN）が連続検出 → 振り返った方向へ 1 回転（右 turn なら右に 1 回転 -360°、左 turn なら左に 1 回転 +360°）を約 0.8 秒で素早く回り切る。
   ※ turn を実行中に次の動き（しこ立ち・足上げ・ステップ）が検出された場合は、即座に回るのをやめて（遅延ゼロで）次の動きへ移行する。
3. 足上げ（優先順位 2）:
   軸足が地面に残り、片方の膝・足首が真上（Y 軸上方向）へ胴の長さの 14% 以上持ち上がったとき → 上げた足の外側（斜め前）へ前進する（右足上げ→右斜め前に前進、左足上げ→左斜め前に前進）。足を下ろすと元の位置へ戻る。
4. ステップ（優先順位 3）:
   脚軸方向の伸展差（dproj_a）および 3D 前方投影から判定。
   - 右足ステップ 1 回目: 前へ進む（基準 +0.12m / 大振幅 +0.30m）
   - 右足ステップ 2 回目以降（連続検出時）: 一度少し後ろに下がったあと（+0.30 × STEP_DIST）、1 回目と同じ位置まで前に行く
   - 左足ステップ 1 回目: 後ろへ進む（基準 -0.12m / 大振幅 -0.30m）
   - 左足ステップ 2 回目以降（連続検出時）: 一度少し前に向かったあと（-0.30 × STEP_DIST）、1 回目と同じ位置まで後ろに行く
   - 連続しない場合: 進んでから元の位置（0.0m）に戻る。
5. つなぎ動作（待機中・一時未検出時）:
   大きな動作の合間の待機中や一時的に人が検出できない間も静止せず、次に人が認識されるまでの動きに滑らかに繋げるように動く。

## 作成・変更したファイル
### whill フォルダ（実機 WHILL 通信ブリッジ）
- whill/whill_bridge.py        … ROS 2 の /cmd_vel と /dance_pose を rosbridge (WebSocket 9091) 経由で受け取り、WHILL のジョイスティック倒し量（%）に変換して送信する。実行ごとに日時付きの別 CSV ファイル（whill_live_YYYYMMDD_HHMMSS.csv）を自動作成する機能を実装（--csv。追従の版にまとめた）。
- whill/whill_check.py         … WHILL Model CR とのシリアル接続・電池残量確認・微小動作テスト用スクリプト
- whill/requirements.txt       … Windows 側で必要な Python ライブラリ一覧
- whill/手順.md                … WHILL Model CR の接続手順と安全の決まり

### follow フォルダ（Gazebo 3D 車いすシミュレーション）
- follow/ros2_ws/src/wheelchair_follower/wheelchair_follower/eisa_dance_node.py
  … Gazebo 3D 空間の車いすを骨格推定データ（UDP 5006 / rosbridge 9091）または自動演舞デモで踊らせる制御ノード。真値オドメトリによる閉ループ初期位置復帰・1 回転ターン・足上げ斜め前進に対応。
- follow/ros2_ws/src/wheelchair_follower/wheelchair_follower/pose_mapping.py
  … finger_dance と共通の 33 関節特徴量抽出・家具誤検出フィルタ・エイサー動作マッピング＆高速追従器（Follower）
- follow/ros2_ws/src/wheelchair_gazebo/launch/eisa_dance_demo.launch.py
  … 3D 車いす単体を軽量ワールドにスポーンし、真値オドメトリ（/wheelchair/ground_truth）をブリッジして高速に動作させる Launch ファイル
- follow/ros2_ws/src/wheelchair_gazebo/worlds/eisa_dance.world
  … 重い人物メッシュやオフスクリーンセンサ描画を省き、Gazebo の起動と動作を高速化した専用ワールド
- follow/ros2_ws/src/wheelchair_description/urdf/wheelchair.urdf.xacro
  … 急後退（しこ立ち・左足ステップ）時の前輪浮き・ピッチ角転倒を防ぐ後輪補助キャスターを追加した車いす 3D モデル

### ros2_ws フォルダ（骨格推定・ダンス制御・CSV解析・視覚化）
- ros2_ws/src/finger_dance/finger_dance/pose_mapping.py
  … 33 関節から胴の長さ（torso）基準の変化率を計算し、人の向き追従・しこ立ち・turn（1 回転＋即時中断）・足上げ（右/左斜め前進）・連続ステップ（2 回目以降の引き戻し→前進）・つなぎ動作を判定する中核モジュール
- ros2_ws/src/finger_dance/finger_dance/pose_detect.py
  … MediaPipe Pose Landmarker による 33 関節骨格検出とプレビュー画像配信（背景の椅子・机の誤描画防止フィルタ付き）
- ros2_ws/src/finger_dance/finger_dance/pose_dance.py
  … 目標角度・前後位置から速度指令（/cmd_vel）と Gazebo 連携パケット（/eisa_state, UDP 5006）を送り、同時に live_camera_dance.csv / camera_dance_<日時>.csv を自動記録するノード
- ros2_ws/src/finger_dance/finger_dance/video_source.py
  … 動画ファイルを実時間（1.0 倍速）でフレーム配信するノード
- ros2_ws/src/finger_dance/launch/pose_dance.launch.py
  … カメラ入力（source:=camera）または動画入力（source:=file）で骨格推定ダンスシステム一式を起動する Launch ファイル
- ros2_ws/analysis/offline_dance.py
  … ダンス動画（mirukumunari.mp4 等）からオフラインで骨格推定値・動作名・WHILL 指令値を進捗表示付きで CSV に書き出すスクリプト
- ros2_ws/analysis/visualize_mirukumunari.py
  … お手本動画（mirukumunari.mp4）の骨格棒人間と、上から見た WHILL の動き（お手本 vs 第 1 段階）を横並び動画（MP4）として出力するスクリプト
- ros2_ws/analysis/visualize_csv_comparison.py
  … mirukumunari_dance.csv と whill_live_*.csv（「指令なし」の遅延フレームを自動除外・時刻同期）の動きを横並びで比較動画（MP4）にするスクリプト

## 安全の決まり（whill/手順.md のとおり）
- 人を乗せない。車いすの周り 1 m 以上を空ける。車いす本体の電源ボタンを押せる人をそばに置く。先生の立ち会いのもとで動かす。
- 実行前に必ず --dry-run で送る値を確かめる。最初は車輪を浮かせた状態や小さい出力（--front-cap 15 --side-cap 20 など）から確認する。
- とっさに止めたいときは whill_bridge.py のターミナルで Enter キー（即時 0% 停止）または Ctrl + C、緊急時は車いす本体の電源ボタンを押す。
