# 環境の値（見本）

書類やこのリポジトリでは、公開してはいけない値を `<ロボットのIP>` のような書き方にしてある。本当の値は、このファイルを `docs/環境の値.local.md` に写して書き込み、手元だけに置く（`*.local.md` は `.gitignore` に入っているので、コミットされない）。学生には、先生が口頭か学内の連絡で伝える。

| 書き方 | 意味 | 本当の値 |
|---|---|---|
| `<ロボットのIP>` | 研究用ロボット chibamouse1 の IP アドレス（研究用ルータの DHCP 手動割当） | |
| `<ルータのIP>` | 研究用ルータの設定画面の IP アドレス | |
| `<ルータが配るIP>`・`<ネットワークの番号>` | 研究用ルータが配る IP アドレスの範囲と、その前半 3 つの数 | |
| `<研究用ルータのSSID>` | 研究用ルータの Wi-Fi の名前（パスワードは書かない） | |
| `<授業用ルータのSSID>` | 授業用ルータの Wi-Fi の名前（SD カードを作るときだけ使う） | |
| `<MACアドレス>` | chibamouse1 の Wi-Fi の MAC アドレス | |
| `<専攻科実験の教材フォルダ>` | 専攻科実験の教材の置き場所 | |
| WHILL の USB-RS232C の装置名 | `ls /dev/cu.usbserial*` で調べる。FTDI の変換ケーブルでは `/dev/cu.usbserial-` の後に部品の番号が付く | |

Wi-Fi のパスワードは、このファイルにも書かない。
